# Licensing status

This release does **not** assign a repository-wide software or data license.

That is intentional: choosing an open-source license determines what downstream users may copy, modify, redistribute, sublicense, or incorporate into other work, and no such choice is made automatically on the author's behalf by this release-maintenance pass.

Until the author selects a license, the original PREF-CAL code, prompts, report source, and evidence should be treated under the default copyright rules applicable to the repository host and jurisdiction.

Third-party font files under `reports/source/fonts/` retain the license terms in their adjacent `LICENSE-*` files. Those font licenses do not license the PREF-CAL code, report, prompts, or evidence.

Before describing the repository as "open source," select and add an explicit software license (for example, MIT, BSD-3-Clause, or Apache-2.0) and separately decide whether the report/evidence should use the same or different terms.
